# Photonicat Companion 0.7.6 beta

Исправлено подключение Android по Bluetooth после запуска роутера. Если Bluetooth-адаптер появляется позже службы Companion, она повторяет попытку подключения. Управление по локальной сети продолжает работать; ключ и выбранный адаптер сохраняются.

Все установщики пересобраны с исправленной службой для **новой установки на роутер**. Замена приложения на телефоне или компьютере сама по себе не обновляет службу на уже настроенном роутере. Повторная привязка сохраняет существующий ключ. Для старой службы временный способ восстановить Bluetooth описан в разделе устранения неполадок README; повторно устанавливать весь комплект на действующий роутер ради этого не нужно.

Сохранены автоматическое переподключение Mac и Windows при смене Wi-Fi/Ethernet, панель в строке меню или области уведомлений и автозапуск по выбору.

## Проверки

- Анализ Flutter и 39 тестов клиента; 56 Python-тестов, включая позднее появление Bluetooth-адаптера, отмену подключения и освобождение ресурсов после ошибки.
- На действующем роутере после исправления восстановилось защищённое Bluetooth-подключение Samsung. Модем, Wi-Fi и Mihomo при этом не перезапускались.
- Android: версия 0.7.6 / 14, Android 12+, подпись совпадает с предыдущей тестовой сборкой; обновление сохраняет данные приложения.
- Mac: сборка arm64, подпись и содержимое DMG.
- Windows: сборка, установка, скрытый автозапуск, установка без автозапуска и очистка при удалении в Windows-среде сборки.
- Встроенный пакет службы сверяется с проверенным исходником во всех сборках.

## Ограничения

Полный путь на заводском роутере, повторная загрузка действующего роутера и реальная сеть Windows в этом выпуске не проверялись. Мастер рассчитан на Photonicat 2 с PhotonicatWrt 26.04.1. Исправление касается появления адаптера при старте службы; восстановление после произвольного перезапуска BlueZ не заявляется.

Это тестовый выпуск: APK использует тестовый сертификат, Windows EXE не подписан, Mac подписан сертификатом разработки Apple без нотариализации. Ключи подписи, личный ключ Companion, подписки и профили владельца в исходники и установщики не включаются. Собственный протокол управления не проходил независимый аудит безопасности. Проект независим от производителя.

В приложениях сохранены ваши настройки. Перед удалением приложения сохраните ключ роутера отдельно.

Контрольные суммы — в `SHA256SUMS`. Полные исходники — в `Photonicat-0.7.6-Source.zip`, снимок для настольной сборки — в `Desktop-Source.zip`. Исходники Mihomo и AmneziaWG и лицензии приложены отдельно.
