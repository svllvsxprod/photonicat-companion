# Установка и использование Photonicat Companion 0.7.5

[Скачать установщики и APK](https://github.com/svllvsxprod/photonicat-companion/releases/tag/v0.7.5-beta.1) · [Мастер настройки со скриншотами](SETUP_RU.md)

Это тестовый выпуск для Photonicat 2. Для первичной установки службы поддерживается штатная PhotonicatWrt 26.04.1. Полный проход с заводского состояния ещё не проверен. Приложение не заменяет прошивку и не устанавливает драйверы модема или Wi-Fi.

## Какой файл скачать

| Устройство | Файл в релизе | Управление роутером |
| --- | --- | --- |
| Mac с Apple Silicon, macOS 12+ | `Photonicat-0.7.5-beta.1-macOS-AppleSilicon.dmg` | По Wi-Fi или Ethernet |
| Windows x64 | `Photonicat-0.7.5-Windows-x64-Setup.exe` | По Wi-Fi или Ethernet |
| Windows без установки | `Photonicat-0.7.5-Windows-x64.zip` | Распаковать целиком, запустить `photonicat.exe` |
| Android 12+ | `Photonicat-0.7.5-Android.apk` | По Bluetooth LE |

В релизе приложены исходники и контрольные суммы SHA-256. APK подписан текущим тестовым сертификатом проекта. Windows EXE пока без цифровой подписи, Mac DMG — с подписью разработки Apple, без нотариализации. Если система запрещает запуск, не отключайте системную защиту целиком: проверьте источник файла и используйте собственную сборку либо дождитесь подписанного публичного выпуска.

## Если роутер только из коробки

1. Подключите его к питанию и настройте административный пароль в штатном интерфейсе. Пароль Wi-Fi не является паролем SSH.
2. Подключите компьютер к LAN или Wi-Fi этого роутера. WAN для управления подходит только когда порт настроен на раздачу клиентам; порт приёма внешнего интернета не является клиентской сетью.
3. Установите Companion на компьютер. На Mac перенесите приложение из DMG в «Программы»; на Windows пройдите установщик.
4. Откройте значок кота в строке меню Mac или области уведомлений Windows. На Windows он может быть под стрелкой скрытых значков.
5. Нажмите **«Настроить роутер»**. Укажите его локальный адрес и пароль root/SSH. Мастер обнаружит оборудование и покажет проверки совместимости.
6. Следуйте [четырём шагам мастера со скриншотами](SETUP_RU.md#шаг-1-подключение). Если мастер сообщает о конфликте, сохраните текст и не обходите проверку вручную.
7. На последнем шаге сохраните ключ в менеджере паролей. Компьютер уже получит его автоматически; этот же ключ понадобится телефону и другим компьютерам.

Без установленной службы Companion телефон не сможет управлять новым роутером по Bluetooth. Первичная установка службы выполняется с Mac или Windows.

## Установка на Android

1. Скачайте APK из релиза на телефон и откройте файл. При запросе Android разрешите установку из этого конкретного браузера или файлового менеджера; после установки разрешение можно отключить.
2. Для обновления используйте установку поверх существующего приложения. Если Android сообщает о конфликте подписи, не удаляйте старое приложение, пока не сохранён ключ роутера: другая сборка могла быть подписана иным сертификатом.
3. Включите Bluetooth и откройте Photonicat рядом с роутером.
4. Вставьте ключ из последнего шага компьютерного мастера в поле **«Ключ своего роутера»**. Это 64 символа `0–9` и `a–f`, не пароль Wi-Fi и не VPN-подписка.
5. Нажмите **«Привязать Photonicat»** и разрешите доступ к устройствам поблизости, если Android запросит его.
6. Дождитесь показателей во вкладке **«Состояние»**. После привязки ключ хранится в защищённом хранилище телефона.

Подключаться к Wi-Fi роутера для управления с Android не обязательно. Для передачи интернет-трафика телефона через роутер подключитесь к его Wi-Fi отдельно. При сворачивании Android-приложения связь управления приостанавливается; постоянная фоновая работа не заявляется.

## Привязка ещё одного компьютера

Подключите компьютер к клиентской сети Photonicat. В начальном экране вставьте сохранённый ключ и нажмите **«Привязать Photonicat»**. Поле **«Адрес роутера (необязательно)»** можно оставить пустым для автоматического поиска. Если автоматический поиск не помог, укажите IPv4-адрес из свойств подключения или штатного веб-интерфейса.

Повторная настройка уже установленной службы не должна создавать другой ключ: мастер умеет привязаться к существующей службе. Не пересылайте ключ в публичный чат и не выкладывайте скриншот с раскрытым значением.

## Wi-Fi ↔ Ethernet на Mac и Windows

Оставьте хотя бы одно рабочее подключение к клиентской сети Photonicat. При потере прежнего соединения приложение повторно проверяет сетевые адаптеры и ищет роутер с сохранённым ключом. Это работает в обоих направлениях; повторная привязка не требуется.

Переподключение занимает некоторое время, а не происходит мгновенно. Пока связи нет, последние показатели не подтверждают текущее состояние роутера. Команда, отправленная в момент обрыва, не повторяется автоматически: после восстановления проверьте результат перед повторным нажатием.

Кнопка **«Отключить»** останавливает автоматические попытки намеренно. Для возобновления нажмите **«Подключиться»**. Если оба подключения потеряны, приложение не сможет восстановить доступ до возвращения сети.

## VPN и основные разделы

| Раздел | Что делать |
| --- | --- |
| Состояние | Смотреть батарею, температуру, CPU, память и скорости; учитывать актуальность данных. |
| Устройства | Смотреть клиентов и аренды DHCP. Аренда сама по себе не подтверждает, что устройство онлайн. |
| VPN | Добавить подписку Mihomo или профили AmneziaWG, обновить списки, выбрать сервер и основное ядро. |
| Роутер | Управлять Wi-Fi, экраном, вентилятором и настройками приложения. |
| СМС | Читать входящие сообщения SIM-карты; отправка и удаление не поддерживаются. |

Для Mihomo нужна HTTPS-ссылка подписки формата Clash/Mihomo из кабинета вашего провайдера. Для AmneziaWG нужен клиентский `.conf`, полученный у провайдера или экспортированный из Amnezia. В разделе VPN доступны импорт файла и QR; для сканирования QR нужна камера и разрешение на неё. Ни ключ Companion, ни административный пароль роутера не заменяют VPN-профиль.

На каждом ядре выбирается один профиль. Для нужного клиентского интерфейса выберите **Direct** или **VPN**. Direct использует обычный интернет; VPN — выбранное основное ядро с kill switch. Если этот туннель недоступен, трафик защищаемого подключения должен блокироваться. Переключение сети, через которую сейчас подключён компьютер, может временно оборвать управление. Мастер импорта не включает VPN автоматически. GearUP в этой версии из приложения удалён.

## Автозапуск и окно

На компьютере откройте **«Роутер» → «Приложение на компьютере» → «Запускать при входе в систему»**. На Mac переключатель доступен с macOS 13; система может потребовать подтверждение в настройках объектов входа. На Windows автозапуск также можно выбрать в установщике. Он не включается без выбора пользователя.

Нажатие на значок кота раскрывает панель. Закрытие панели не завершает приложение; для полного выхода используйте **«Завершить»** в меню значка. Полосы прокрутки на компьютере скрыты, прокрутка колёсиком/трекпадом сохраняется.

## Если связь не появилась

- **Android:** проверьте Bluetooth, разрешение «Устройства поблизости», расстояние и ключ. Служба Companion должна быть установлена на роутере.
- **Mac/Windows:** проверьте доступ к локальному адресу роутера и наличие клиентского подключения. Подключение к стороннему Wi-Fi само по себе не даёт доступ к Photonicat.
- **После смены сети:** подождите завершения поиска. Если ранее нажали «Отключить», нажмите «Подключиться». При нестандартной адресации проверьте указанный адрес.
- **Ключ потерян:** повторно откройте мастер с административным доступом и привяжитесь к уже установленной службе. Не публикуйте содержимое ключа при обращении за помощью.
- **VPN недоступен:** проверьте работу выбранного сервера и подписки. В режиме VPN отсутствие интернета при упавшем туннеле может быть ожидаемой работой kill switch.

При сообщении об ошибке укажите версию приложения, ОС, способ подключения и текст ошибки. Удалите из сообщения ключи, пароли, ссылки подписок и содержимое VPN-конфигов.
