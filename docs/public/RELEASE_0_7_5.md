# Photonicat Companion 0.7.5 beta

Тестовый выпуск от 17 ноября 2026 для Android, Mac с Apple Silicon и Windows x64.

## Скачать и настроить

- **Android 12+:** `Photonicat-0.7.5-Android.apk`.
- **Mac, Apple Silicon, macOS 12+:** `Photonicat-0.7.5-beta.1-macOS-AppleSilicon.dmg`.
- **Windows x64:** `Photonicat-0.7.5-Windows-x64-Setup.exe`; portable-вариант — `Photonicat-0.7.5-Windows-x64.zip`.
- [Установка и повседневное использование](https://github.com/svllvsxprod/photonicat-companion/blob/main/README.ru.md).
- [Первичная настройка роутера со скриншотами](https://github.com/svllvsxprod/photonicat-companion/blob/main/README.ru.md#первая-настройка-роутера).

Скачивайте файлы из [этого выпуска](https://github.com/svllvsxprod/photonicat-companion/releases/tag/v0.7.5-beta.1). Контрольные суммы находятся в `SHA256SUMS`. `Photonicat-0.7.5-Source.zip` содержит опубликованные исходники всех платформ, `Desktop-Source.zip` — снимок исходников настольных сборок. Отдельно приложены исходники Mihomo/AmneziaWG, используемых в пакете настройки, и лицензии.

## Изменения

- Автоматическое восстановление управления на компьютере при переходе Wi-Fi → Ethernet и обратно.
- Поиск роутера по шлюзам всех активных адаптеров, сохранённому адресу и стандартным клиентским адресам. Кандидат принимается только после проверки сохранённого ключа.
- Быстрее обнаруживается зависшее соединение; ошибка отправки больше не останавливает дальнейшие попытки подключения.
- Команда управления с потерянным ответом не повторяется автоматически. После восстановления нужно проверить результат.
- В опубликованные исходники вошли настольный мастер установки, панель Mac, панель Windows с позиционированием относительно области уведомлений, автозапуск по выбору и скрытые полосы прокрутки.
- Обновлены инструкции. В Android сохранено управление по Bluetooth; смена Wi-Fi/Ethernet относится к компьютерным версиям.

## Проверки

- Анализ Flutter и 39 тестов прошли на Mac и Windows, в том числе оба направления переподключения, зависший канал, неверный ключ и отсутствие повторной отправки команды.
- Реальный роутер снова начал отдавать защищённые данные после имитации потери адаптера в тесте. Сеть ОС и действующий VPN при этом не переключались.
- Mac arm64: сборка, подпись и образ проверены; установленная версия — 0.7.5.
- Windows: сборка, установка, скрытый автозапуск, отключённый по умолчанию автозапуск и очистка при удалении проверены в Windows-среде сборки.
- Android: release-сборка, идентификатор `dev.svllvsx.photonicat`, версия 0.7.5 / 13, Android 12+ и подпись проверены. Сертификат совпадает с предыдущей локальной тестовой сборкой.

## Ограничения тестового выпуска

Физическое отключение Wi-Fi/кабеля для проверки этой версии не выполнялось. Новый APK при подготовке выпуска не запускался на телефоне. Полный путь установки службы на заводской роутер и реальная сеть Windows ещё требуют проверки. Поддерживаемая мастером система — PhotonicatWrt 26.04.1 на Photonicat 2.

APK подписан текущим тестовым сертификатом; Windows EXE пока не подписан; Mac использует сертификат разработки Apple без нотариализации. Это не беспрепятственный массовый выпуск для всех систем. Для собственного распространения настройте свою подпись. Ключи подписи не входят в исходники.

Служба, установленная на роутере, не обновляется от замены компьютерного приложения сама по себе. Не запускайте переустановку службы на действующем роутере только ради обновления приложения.

В пакетах нет личного ключа Companion, VPN-подписок и профилей владельца. При обновлении сохраняйте существующую привязку; перед удалением приложения сохраните ключ отдельно. Собственный протокол управления не проходил независимый аудит безопасности. Проект независим от производителя.
