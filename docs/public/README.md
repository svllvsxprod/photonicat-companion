# Photonicat Companion 0.7.6 — тестовая версия

Приложение для управления Photonicat 2 со смартфона и компьютера.
Настольная версия работает через локальную сеть. На Mac окно открывается
по нажатию на жёлтый значок в строке меню.

Новый мастер помогает установить службу управления и VPN-ядра на совместимый
роутер, получить его ключ и привязать приложение без ручного копирования.

**Статус:** проверены интерфейс Mac, обнаружение оборудования на действующем
роутере, проверки конфигурации и автоматические тесты. Полный цикл установки
на заводской роутер ещё не пройден. Windows x64 собрана в GitHub Actions:
прошли установка, проверка сохранения процесса после запуска и удаление.
Клики по интерфейсу и связь с реальным роутером на Windows ещё не проверены.
Это версия для ограниченного тестирования, а не объявление готового массового релиза.

- [Пошаговая инструкция](SETUP_RU.md).
- Mac: Apple Silicon, macOS 12 или новее.
- Роутер: Photonicat 2, штатная PhotonicatWrt 26.04.1, доступ администратора по SSH.
- Windows: установщик x64; требуется отдельная проверка интерфейса и связи с устройством.

- Android: Android 12+, APK доступен в [релизе 0.7.6](https://github.com/svllvsxprod/photonicat-companion/releases/tag/v0.7.6-beta.1).
- [Установка Android и повседневное управление](USAGE_RU.md).
- [Что изменилось в 0.7.6](RELEASE_0_7_6.md).

## Сборка

Flutter 3.44.2 и Dart 3.12.2, Xcode для Mac; Flutter, Visual Studio с C++ и
Inno Setup 6.3+ для Windows. Сначала выполните `flutter pub get` в `mobile`.
Сборка Mac: `tools/build-macos.sh`. Сборка Windows: `tools/build-windows.ps1`.
Артефакты Windows сохраняются в локальную папку `releases/private/0.7.6-beta.1`.

Публичный архив содержит проверенный пакет служб для ARM64. Чтобы пересобрать
его из закреплённых исходников и официального бинарного выпуска, запустите
`python3 tools/build-public-payload.py` с установленным Go.
Mihomo и AmneziaWG устанавливаются только на роутер.

Лицензии VPN-ядер: `mobile/assets/setup/*LICENSE.txt`, версии и ссылки на
исходники — `mobile/assets/setup/NOTICE.txt`. Сохранены лицензии библиотек
и шрифтов. Перед публичной раздачей бинарников приложите соответствующие
исходники и уведомления всех компонентов; эта сборка пока предназначена для проверки.

## Данные доступа

В приложении нет готового ключа владельца, VPN-подписок или профилей AmneziaWG.
Новый ключ создаётся на каждом роутере отдельно. При повторной привязке
используется существующий ключ. Пароль администратора нужен только для SSH-сеанса
настройки; он не сохраняется. Ключ управления сохраняется в защищённом хранилище ОС.

Не публикуйте целиком рабочую папку разработчика. Для подготовки отдельного
архива используйте `tools/export-public-source.py`: он копирует только разрешённые
файлы. `releases`, `output`, локальные ключи и журналы исключены из Git.

Это независимое приложение, не официальный продукт производителя Photonicat.
Протокол управления ещё не проходил независимый аудит безопасности.
